## 课程与学习建议

### COSC0007 数据结构
- 应对考试个人感觉 **刷王道就 ok**。
- 建议重点关注：
  - 基本数据结构的性质与操作
  - 树、图、查找、排序等高频题型
  - 代码题/算法题的常见模板与复杂度分析

### COSC0013 数据库系统
- 理论课：**看 PPT 即可速通**，重点把概念、范式、事务、并发控制、恢复等内容捋清楚。
- 上机：2026 年难度有所提升，但整体还算友好。
- 个人建议：
  - 考前一周集中练一练，上机拿满分问题不大
  - 注意一些理论课可能没详细讲、但上机很好用的 SQL 关键字和写法，例如：
    - `limit`
    - `with as`

### COSC0015 人工智能导论
- 个人感觉是 **帮助很大的一门课**，对科研入门很有帮助。
- 应对考试可以参考资料仓库中的：
  - **题型总结**：主要用于应对大题
  - **知识点总结**：主要用于应对选择题和简答题
- 建议不要只背结论，最好理解经典算法、搜索、机器学习基础等内容的基本思想。

### COSC0016 算法导论
- 复习重点是 **总结课件伪代码，理解其含义和相关知识点**。
- 个人推荐复习方式：
  1. 按章节整理课件中的核心算法伪代码
  2. 理解每段伪代码在做什么、为什么正确
  3. 结合复杂度分析和适用场景一起记忆
  4. 考前每天默一遍伪代码，加深熟练度
- 亲测：考前反复默写伪代码对考试很有帮助。

### COSC0025 并行程序设计
- 伟大无需多言，**卷报告就完事了**。
- 建议平时实验和报告认真做，尽量把实现思路、性能对比和结果分析写完整。
- 如果时间允许，可以多关注：
  - 并行加速比与效率分析
  - OpenMP / MPI / CUDA 等并行模型的基本使用
  - 实验结果的可视化与解释

### COSC0043 计算机组成原理
- 平时没事可以跟着 B 站 **“翼云”** 学一学，理解会更顺。
- 本人是考试前两天速通，结合王道看的。
- 考试体感：
  - 选择题比较简单
  - 大题结合王道后会发现计算题主要就是几类固定题型
- 重点题型包括：
  - C 语言转 MIPS
  - 流水线冒险
  - Cache 命中率/地址划分
  - 指令系统、存储系统等相关计算
- 仓库中有相应练习题，建议考前集中刷一遍。

### COSC0069 计算机硬件基础
- 每年题型相对固定，**速通友好**。
- 个人感觉和后续课程关联较少，适合考前按题型集中复习。
- 建议优先把常考概念和固定题型整理出来，复习效率会比较高。

### COSC0060 数据可视化
- 课上题要认真写，平时积累会直接影响最后效果。
- 最后大作业建议：
  - 尽早确定选题
  - 多和老师交流
- CS d 课，神中神。
